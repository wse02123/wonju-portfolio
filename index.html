현상 분석

사용자는 대출·카드·보험·지원금 신청 등 본래의 목적을 처리하던 중 갑자기 증명서 제출 화면을 만나게 됩니다. 스크래핑 특성상 홈택스·정부24·대법원 등 외부기관 인증과 오류 케이스가 많았고, 진행 상태와 실패 원인을 알기 어려운 상태에서 반복적으로 민원이 제기되고 있었습니다.

민원 수집 — 고객센터·이메일·고객사 담당자 채널별 분류 화면 단위 분류 — 서비스 진입부터 결과 안내까지 전 구간 분석

분석 01 · 최초 랜딩

주요 민원"이걸 갑자기 왜 해야 하냐" / "스팸 아니냐" / "금융상품 신청하려는데 왜 다른 화면으로 넘어오냐"
사용자 상황금융상품을 신청할지 말지 고민하던 중, 예상하지 못한 증명서 제출 절차를 만남.
화면 이슈서비스 목적과 사용자 목적이 연결되지 않아 첫 진입부터 불신과 거부감이 발생함.

분석 02 · 증명서 신청서 작성

주요 민원"똑같은 걸 왜 계속 입력하냐" / "용어가 어려워서 뭘 입력해야 하는지 모르겠다" / "나는 이런 상황인데 뭘 선택해야 하냐"
사용자 상황목적은 명확하지만 마음이 급해 안내 문구를 꼼꼼히 읽지 않음.
화면 이슈한 번에 많은 정보와 선택지를 요구해 사용자의 인지부하가 높아짐.

분석 03 · 스크래핑 직후 안내

주요 민원"오류가 자꾸 나서 못하겠다" / "빨리 대출받아야 하는데 뭐가 문제인지 모르겠다" / "다시 처음부터 해야 하냐"
사용자 상황외부기관 인증 오류와 스크래핑 실패를 직접 해결해야 하지만, 원인과 다음 행동을 이해하기 어려움.
화면 이슈진행 상태·실패 원인·재시도 방법이 불명확해 사용자가 서비스에 장애가 있다고 느낌.

핵심 인싸이트 — UX 심리학 관점에서 사용자의 부정적 감정을 최초 목적으로 포커스를 이동시키고, 친절한 안내를 통해 빠르게 다음 Step으로 나아갈 수 있게 도와주어야 했습니다.
① 절차의 이유를 납득시켜야 한다  ② 한 번에 많은 정보를 요구하지 않고 단계별로 안내한다
③ 진행 상태와 남은 과업을 보여줘야 한다  ④ 오류 앞에서도 다음 행동을 할 수 있어야 한다

AI Utilization · 01

가상의 페르소나 UT로
기획안 검증

신규 서비스 또는 기존 서비스 개선 시, 실제 UT 전에 Figma 프로토타입만으로 사용자 페인포인트 가설을 발굴할 수 있는 Claude Code 커스텀 스킬입니다. 150인 페르소나 라이브러리와 단계별 시뮬레이션으로 가설을 빠르고 저비용으로 검증합니다.

How It Works

3단계 단계별 시뮬레이션

1st

1차 스캔 — 전체 훑기

150인 페르소나 라이브러리에서 서비스 타겟에 맞는 인원을 선정합니다. 전체 화면 흐름을 빠르게 훑으며 주요 마찰 지점을 1차로 파악한 뒤 결과를 보고하고 계속 여부를 확인합니다.

2nd

2차 집중 검증 — 페인포인트 심층 탐색

1차에서 발견된 마찰 구간을 중심으로 타겟 페르소나가 실제로 이탈하거나 혼란을 겪는 지점을 집중 검증합니다. 단계마다 결과를 보고하여 불필요한 시뮬레이션을 최소화합니다.

3rd

3차 커버리지 확장 — 엣지케이스 탐색

다양한 연령·상황·디지털 친숙도를 가진 페르소나로 커버리지를 확장해 일반화 가능한 인사이트를 확보합니다. 필요한 만큼만 실행하여 컨텍스트를 효율적으로 사용합니다.

텔레그램으로 자료·기프티콘·일정 등을 전달하면 정보를 확인하고 저장·분류한 뒤, 매일 아침 일정 보고를 해주는 나만의 전담 비서입니다. Oracle DB와 Google 생태계에 연동하여 모든 정보가 자동으로 정리됩니다.

자료 아카이브

🎁
기프티콘 관리
기프티콘 이미지를 보내면 유효기간과 사용처를 추출해서 Oracle DB에 등록하고 만료 전 알림을 줍니다.
📅
일정 등록
자연어로 일정을 보내면 날짜·시간·장소를 파악해서 Google Calendar에 자동 등록합니다.

Tech Stack

사용 툴

Claude Code

자료 분류, 일정 파싱, 기프티콘 정보 추출 등 지능적인 처리 작업 담당. n8n 워크플로우에서 호출

Telegram

사용자 인터페이스 역할. 자료 수신 및 아침 보고 발송. 봇 명령어로 즉시 조회도 가능

n8n

워크플로우 자동화 허브. Telegram 수신 → 분류 → DB 저장 → 알림 발송의 전체 파이프라인 관리

Oracle

모든 아카이브 데이터의 영구 저장소. 자료·기프티콘·히스토리를 구조화하여 관리

Google

Google Calendar (일정), Google Sheet (리포트), Google Cloud (파일 저장) 연동으로 생태계 통합
